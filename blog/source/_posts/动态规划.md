## 动态规划（DP）

## 1.前言

### 1.1DP是什么？

{% note purple 'fas fa-wand-magic-sparkles' %}
DP（动态规划） 是什么？
{% endnote %}

动态规划适合解决一类问题：

```text
一个大问题的答案，可以由若干小问题的答案推出来。
并且这些小问题会被反复用到。
```

比如斐波那契：

```cpp
f(n) = f(n - 1) + f(n - 2)
```

如果递归暴力算，会重复计算很多次。
DP 就是把这些结果存下来。

### 1.2做 DP 题的四步

做任何 DP 题，都按这四步走：

```text
1. 定义状态：dp[i] / dp[i][j] 表示什么？
2. 写状态转移：dp[i] 如何由更小状态推出来？
3. 初始化：最小规模问题的答案是什么？
4. 确定遍历顺序：先算谁，后算谁？
```

其中最重要的是第一步：

```text
状态定义错了，后面全错。
状态定义对了，转移通常就自然出来了。
```

### 1.3DP 和贪心的区别

*贪心*

每一步都做当前看起来最优的选择。

```text
当前最优 -> 希望全局最优
```

比如跳跃游戏：维护当前最远能到哪里。

*DP*

保存所有可能状态，从小问题推大问题。

```text
多个子问题答案 -> 推出当前答案
```

*判断口诀*

```text
只需要维护一个最优指标，通常是贪心。
需要比较多种选择，并保存中间状态，通常是 DP。
```

## 2.一维DP

```cpp
dp[i]
```

常见含义：

```tex
到第 i 个位置为止的答案
以第 i 个位置结尾的答案
长度为 i 的答案
金额为 i 的答案
容量为 i 的答案
```

典型题：

```
爬楼梯
打家劫舍
最长上升子序列
零钱兑换
完全平方数
```

## 3.二维DP

```cpp
dp[i][j]
```

常见含义：

```tex
text1 前 i 个字符和 text2 前 j 个字符的答案
从 i 到 j 这个区间的答案
前 i 个物品放进容量 j 的背包的答案
```

典型题：

```
最长公共子序列
编辑距离
01 背包
最长回文子序列
区间 DP
```

### 爬楼梯

{% note pink 'fas fa-bell' %}
  问题
{% endnote %}

每次可以爬 1 阶或 2 阶，问爬到第 `n` 阶有多少种方法。

{% note pink 'fas fa-bell' %}
  题解
{% endnote %}

**状态定义**

```cpp
dp[i]
```

表示

```text
爬到第 i 阶的方法数。
```

**状态转移**

到第 `i` 阶，有两种来源：

```text
从 i - 1 爬 1 阶上来
从 i - 2 爬 2 阶上来
```

所以：

```cpp
dp[i] = dp[i - 1] + dp[i - 2];
```

**初始化**

```cpp
dp[0] = 1;
dp[1] = 1;
```

`dp[0] = 1` 可以理解为：什么都不做也是一种方法。

**代码**

```cpp
int climbStairs(int n) {
    if (n <= 1) {
        return 1;
    }
    std::vector<int> dp(n + 1);
    dp[0] = 1;// 什么都不做也是1种
    dp[1] = 1;
    for(int i = 2; i <= n; i ++) {
        dp[i] = dp[i - 1] + dp[i -2];
    }
    return dp[n];
}
```

### 打家劫舍

{% note pink 'fas fa-bell' %}
  问题
{% endnote %}

有一排房子，每个房子里有一定金额的钱。小偷不能偷相邻的两间房子。

给你一个数组：

nums[i]

表示第 `i` 间房子的钱数。

求最多能偷多少钱。

{% note pink 'fas fa-bell' %}
  示例
{% endnote %}

```text
输入：nums = [1, 2, 3, 1]
输出：4
```

解释：

```text
偷第 0 间和第 2 间：1 + 3 = 4
```

另一个示例：

```text
输入：nums = [2, 7, 9, 3, 1]
输出：12
```

解释：

```text
偷第 0、2、4 间：2 + 9 + 1 = 12
```

---

{% note pink 'fas fa-bell' %}
  题解
{% endnote %}

```cpp
int rob(std::vector<int>& num) {
    int n = num.size();
    if(n < 0) return 0;
    if(n == 0) return num[0];
    if(n == 1) return std::max(num[0], num[1]);
    std::vector<int> dp(n + 1);
    dp[0] = num[0];
    dp[1] = std::max(num[0], num[1]);
    for(int i = 2; i <= n; i ++) {
        dp[i] = std::max(dp[i-1],dp[i-2] + num[i]);
    }
    return dp[n];
}
```

### 最长上升子序列（LIS）

{% note pink 'fas fa-bell' %}
  问题
{% endnote %}

给一个数组，求最长严格递增子序列长度。

子序列不要求连续。

{% note pink 'fas fa-bell' %}
  题解
{% endnote %}

**状态定义**

```cpp
dp[i]
```

表示：

```text
以 nums[i] 结尾的最长上升子序列长度。
```

注意：这里是 **以 i 结尾**，不是前 i 个元素的整体答案。

**状态转移**

枚举 `j < i`：

```text
如果 nums[j] < nums[i]，说明 nums[i] 可以接在 nums[j] 后面。
```

所以：

```cpp
dp[i] = max(dp[i], dp[j] + 1);
```

**初始化**

每个数自己就是长度为 1 的子序列：

```cpp
dp[i] = 1;
```

**代码**

```cpp
int lengthOfLIS(vector<int>& nums) {
    int n = nums.size();
    vector<int> dp(n, 1);
    int ans = 1;

    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < i; ++j) {
            if (nums[j] < nums[i]) {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
        ans = max(ans, dp[i]);
    }

    return ans;
}
```

{% note pink 'fas fa-bell' %}

```cpp
int longgestCommonSubSequence(string text1, string text2) {
    int m = text1.size();
    int n = text2.size();

    vector<vector<int>> dp(m + 1, vector<int> (n + 1, 0));

    for (int i = 1; i <= m; i ++) {
        for (int j = 1; j <= n; j ++) {
            if (text1[i - 1] == text2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[m][n];
}
```

### 编辑距离

{% note pink 'fas fa-bell' %}
  问题
{% endnote %}

{% note pink 'fas fa-bell' %}
  示例
{% endnote %}

{% note pink 'fas fa-bell' %}
  题解
{% endnote %}



```cpp
int minDistance(string word1, string word2) {
    int m = word1.size();
    int n = word2.size();

    vector<vector<int>> dp(m + 1, vector<int> (n + 1, 0));

    for (int i = 0; i <= m ; i ++) {
        dp[i][0] = i;
    }

    for (int j = 0; j <= m; j ++) {
        dp[0][j] = j;
    }

    for (int i = 1; i <= m; i ++) {
        for (int j = 1; j <= n; j ++) {
            if (word1[i - 1] == word2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = min(dp[i - 1][j - 1] + 1,
                            dp[i - 1][j] + 1);
                dp[i][j] = min(dp[i][j],
                            dp[i][j - 1] + 1);
            }
        }
    }
    return dp[m][n];
}
```

## 5.背包DP

### 01背包

{% note purple 'fas fa-wand-magic-sparkles' %}
01背包特点：每个物品最多选一次。
{% endnote %}



```cpp
int knapsack01(vector<int> & weight, vector<int> & value, int bagWeight) {
    int n = weight.size();
    vector<vector<int>> dp(n, vector<int> (bagWeight + 1));

    for(int j = weight[0]; j <= bagWeight; j ++) {
        dp[0][j] = value[0];
    }

    for(int i = 1; i < n; i ++) {
        for(int j = 0; j <=bagWeight; j ++) {
            if(j < weight[i]) {
                //不放
                dp[i][j] = dp[i-1][j];
            } else {
                //放
                dp[i][j] = max(dp[i - 1][j],dp[i-1][j - weight[i]] + value[i]);
            }
        }
    }
    return dp[n -1][bagWeight];
}
```



**背包问题模版**

```cpp
for (int i = 0; i < n; ++i) {
    for (int j = bagWeight; j >= weight[i]; --j) {
        dp[j] = std::max(dp[j], dp[j - weight[i]] + value[i]);
    }
}
```

### 二叉树最大路径和



```cpp
Class Solution {
public:
    int ans = INT_MIN;
    int dfs(TreeNode* node) {
        if(!node) return 0;

        int leftGain = dfs(node->left);
        int rightGain = dfs(node->right);

        int pathSum = node->val + leftGain + rightGain;
        ans = max(ans, pathSum);

        return node->val + max(leftGain, rightGain);
    }

    int maxPathSum(TreeNode* root) {
        dfs(root);
        return ans;
    }
}
```
