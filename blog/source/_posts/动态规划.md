## 动态规划（DP）

## 1.前言

### 1.1 DP是什么？

{% note purple 'fas fa-wand-magic-sparkles' %}
DP（动态规划） 是什么？
{% endnote %}

动态规划适合解决一类问题：

```text
一个大问题的答案，可以由若干小问题的答案推出来。
并且这些小问题会被反复用到。
```

比如斐波那契：

```cpp
f(n) = f(n - 1) + f(n - 2)
```

如果递归暴力算，会重复计算很多次。
DP 就是把这些结果存下来。

### 1.2 做 DP 题的四步

做任何 DP 题，都按这四步走：

1. 定义状态：dp[i] / dp[i]\[j]表示什么？
2. 写状态转移：dp[i] 如何由更小状态推出来？
3. 初始化：最小规模问题的答案是什么？
4. 确定遍历顺序：先算谁，后算谁？

其中最重要的是第一步：

  状态定义错了，后面全错。
  状态定义对了，转移通常就自然出来了。

### 1.3 DP 和贪心的区别

**贪心**

每一步都做当前看起来最优的选择。

```text
当前最优 -> 希望全局最优
```

比如跳跃游戏：维护当前最远能到哪里。

**DP**

保存所有可能状态，从小问题推大问题。

```text
多个子问题答案 -> 推出当前答案
```

*判断口诀*

```text
只需要维护一个最优指标，通常是贪心。
需要比较多种选择，并保存中间状态，通常是 DP。
```

## 2.一维DP

```cpp
dp[i]
```

常见含义：

```tex
到第 i 个位置为止的答案
以第 i 个位置结尾的答案
长度为 i 的答案
金额为 i 的答案
容量为 i 的答案
```

典型题：

```
爬楼梯
打家劫舍
最长上升子序列
零钱兑换
完全平方数
```

## 3.二维DP

```cpp
dp[i][j]
```

常见含义：

1. text1 前 i 个字符和 text2 前 j 个字符的答案
2. 从 i 到 j 这个区间的答案
3. 前 i 个物品放进容量 j 的背包的答案

典型题：

```
最长公共子序列
编辑距离
01 背包
最长回文子序列
区间 DP
```

### 4.1 爬楼梯

{% note pink 'fas fa-bell' %}
  问题
{% endnote %}

每次可以爬 1 阶或 2 阶，问爬到第 `n` 阶有多少种方法。

{% note pink 'fas fa-bell' %}
  题解
{% endnote %}

**状态定义**

```cpp
dp[i]
```

表示

```text
爬到第 i 阶的方法数。
```

**状态转移**

到第 `i` 阶，有两种来源：

```text
从 i - 1 爬 1 阶上来
从 i - 2 爬 2 阶上来
```

所以：

```cpp
dp[i] = dp[i - 1] + dp[i - 2];
```

**初始化**

```cpp
dp[0] = 1;
dp[1] = 1;
```

`dp[0] = 1` 可以理解为：什么都不做也是一种方法。

**代码**

```cpp
int climbStairs(int n) {
    if (n <= 1) {
        return 1;
    }
    std::vector<int> dp(n + 1);
    dp[0] = 1;// 什么都不做也是1种
    dp[1] = 1;
    for(int i = 2; i <= n; i ++) {
        dp[i] = dp[i - 1] + dp[i -2];
    }
    return dp[n];
}
```

### 4.2 打家劫舍

{% note pink 'fas fa-bell' %}
  问题
{% endnote %}

有一排房子，每个房子里有一定金额的钱。小偷不能偷相邻的两间房子。

给你一个数组：

nums[i]

表示第 `i` 间房子的钱数。

求最多能偷多少钱。

{% note pink 'fas fa-bell' %}
  示例
{% endnote %}

```text
输入：nums = [1, 2, 3, 1]
输出：4
```

解释：

```text
偷第 0 间和第 2 间：1 + 3 = 4
```

另一个示例：

```text
输入：nums = [2, 7, 9, 3, 1]
输出：12
```

解释：

```text
偷第 0、2、4 间：2 + 9 + 1 = 12
```

{% note pink 'fas fa-bell' %}
  题解
{% endnote %}

**状态定义**

```cpp
dp[i]
```

表示：

```text
考虑到第 i 间房子时，最多能偷多少钱。
```

**状态转移**

对于第 `i` 间房子：

```text
1. 不偷第 i 间：dp[i - 1]
2. 偷第 i 间：dp[i - 2] + nums[i]
```

所以：

```cpp
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i]);
```

**初始化**

```cpp
dp[0] = nums[0];
dp[1] = max(nums[0], nums[1]);
```

**代码**

```cpp
int rob(std::vector<int>& num) {
    int n = num.size();
    if(n < 0) return 0;
    if(n == 0) return num[0];
    if(n == 1) return std::max(num[0], num[1]);
    std::vector<int> dp(n + 1);
    dp[0] = num[0];
    dp[1] = std::max(num[0], num[1]);
    for(int i = 2; i <= n; i ++) {
        dp[i] = std::max(dp[i-1],dp[i-2] + num[i]);
    }
    return dp[n];
}
```

偷当前，就不能偷前一个。
不偷当前，就继承前一个。

### 4.3 最长上升子序列 LIS

{% note pink 'fas fa-bell' %}
  问题
{% endnote %}

给一个数组，求最长严格递增子序列长度。

注：子序列不要求连续。

{% note pink 'fas fa-bell' %}
  题解
{% endnote %}

**状态定义**

```cpp
dp[i]
```

表示：

```text
以 nums[i] 结尾的最长上升子序列长度。
```

注意：这里是 **以 i 结尾**，不是前 i 个元素的整体答案。

**状态转移**

枚举 `j < i`：

```text
如果 nums[j] < nums[i]，说明 nums[i] 可以接在 nums[j] 后面。
```

所以：

```cpp
dp[i] = max(dp[i], dp[j] + 1);
```

**初始化**

每个数自己就是长度为 1 的子序列：

```cpp
dp[i] = 1;
```

**代码**

```cpp
int lengthOfLIS(vector<int>& nums) {
    int n = nums.size();
    vector<int> dp(n, 1);
    int ans = 1;

    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < i; ++j) {
            if (nums[j] < nums[i]) {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
        ans = max(ans, dp[i]);
    }

    return ans;
}
```

LIS 的 dp[i] 通常定义为：以 i 结尾。
因为我要知道谁能接到 nums[i] 前面。

### 4.4 最长公共子序列 LCS

{% note pink 'fas fa-bell' %}
  问题
{% endnote %}

给两个字符串，求最长公共子序列长度。

子序列不要求连续。

{% note pink 'fas fa-bell' %}
  题解
{% endnote %}

**状态定义**

```cpp
dp[i][j]
```

表示：

```text
text1 的前 i 个字符，和 text2 的前 j 个字符，最长公共子序列长度。
```

**状态转移**

看最后一个字符：

```cpp
text1[i - 1]
text2[j - 1]
```

如果相等：

```cpp
dp[i][j] = dp[i - 1][j - 1] + 1;
```

如果不相等：

```cpp
dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
```

**初始化**

空字符串和任何字符串的 LCS 都是 0：

```cpp
dp[0][j] = 0;
dp[i][0] = 0;
```

**代码**

```cpp
int longgestCommonSubSequence(string text1, string text2) {
    int m = text1.size();
    int n = text2.size();

    vector<vector<int>> dp(m + 1, vector<int> (n + 1, 0));

    for (int i = 1; i <= m; i ++) {
        for (int j = 1; j <= n; j ++) {
            if (text1[i - 1] == text2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[m][n];
}
```

两个字符串 DP，通常 dp[i][j] 表示两个前缀的答案。
字符相等，看左上角 + 1。
字符不等，看上方和左方最大值。

### 4.5 最长公共子串

{% note pink 'fas fa-bell' %}
  问题
{% endnote %}

求两字符串的最长公共子串的长度。

子序列：不要求连续。
子串：必须连续。

{% note pink 'fas fa-bell' %}
  题解
{% endnote %}

**状态定义**

```cpp
dp[i][j]
```

表示：

```text
以 text1[i - 1] 和 text2[j - 1] 结尾的最长公共子串长度。
```

**状态转移**

如果字符相等：

```cpp
dp[i][j] = dp[i - 1][j - 1] + 1;
```

如果字符不相等：

```cpp
dp[i][j] = 0;
```

因为子串必须连续，断了就归零。

**代码**

```cpp
int longgestCommonSubString(string text1, string text2) {
    int m = text1.size();
    int n = text2.size();

    vector<vector<int>> dp(m + 1, vector<int> (n + 1, 0));
    int ans = 0;

    for (int i = 1; i <= m; i ++) {
        for (int j = 1; j <= n; j ++) {
            if (text1[i - 1] == text2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
                ans = max(ans, dp[i][j]);
            } else {
                dp[i][j] = 0;
            }
        }
    }
    return ans;
}
```

### 4.6 编辑距离

{% note pink 'fas fa-bell' %}
  问题
{% endnote %}

给两个字符串 `word1` 和 `word2`，可以进行：

```text
插入
删除
替换
```

求把 `word1` 转成 `word2` 的最少操作数。

{% note pink 'fas fa-bell' %}
  题解
{% endnote %}

**状态定义**

```cpp
dp[i][j]
```

表示：

```text
word1 的前 i 个字符，转换成 word2 的前 j 个字符，最少需要多少步。
```

**初始化**

```cpp
dp[i][0] = i;  // word1 前 i 个字符变成空串，只能删 i 次
dp[0][j] = j;  // 空串变成 word2 前 j 个字符，只能插入 j 次
```

**状态转移**

如果最后字符相等：

```cpp
dp[i][j] = dp[i - 1][j - 1];
```

如果不相等，有三种操作：

```cpp
删除：dp[i - 1][j] + 1
插入：dp[i][j - 1] + 1
替换：dp[i - 1][j - 1] + 1
```

所以：

```cpp
dp[i][j] = min({
    dp[i - 1][j] + 1,
    dp[i][j - 1] + 1,
    dp[i - 1][j - 1] + 1
});
```

**代码**

```cpp
int minDistance(string word1, string word2) {
    int m = word1.size();
    int n = word2.size();

    vector<vector<int>> dp(m + 1, vector<int> (n + 1, 0));

    for (int i = 0; i <= m ; i ++) {
        dp[i][0] = i;
    }

    for (int j = 0; j <= m; j ++) {
        dp[0][j] = j;
    }

    for (int i = 1; i <= m; i ++) {
        for (int j = 1; j <= n; j ++) {
            if (word1[i - 1] == word2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = min(dp[i - 1][j - 1] + 1,
                            dp[i - 1][j] + 1);
                dp[i][j] = min(dp[i][j],
                            dp[i][j - 1] + 1);
            }
        }
    }
    return dp[m][n];
}
```

## 5.背包DP

背包问题的核心：

```text
有物品，有容量，有选择限制，求最大价值 / 最小数量 / 方案数。
```

常见类型：

```text
01 背包：每个物品最多选一次。
完全背包：每个物品可以选无限次。
多重背包：每个物品有固定数量。
分组背包：每组最多选一个。
```

---

### 5.1 ‘’01背包‘’问题

{% note purple 'fas fa-wand-magic-sparkles' %}
01背包特点：每个物品最多选一次。
{% endnote %}

{% note pink 'fas fa-bell' %}
  问题
{% endnote %}

有 `n` 个物品：

```text
weight[i] 重量
value[i]  价值
```

背包容量为 `bagWeight`。

每个物品最多选一次，求最大价值。

{% note pink 'fas fa-bell' %}
  题解
{% endnote %}

**二维状态定义**

```cpp
dp[i][j]
```

表示：

```text
从下标 0 到 i 的物品里任意选择，放进容量 j 的背包，最大价值是多少。
```

**二维状态转移**

对于物品 `i`：

```text
不选 i：dp[i - 1][j]
选 i：dp[i - 1][j - weight[i]] + value[i]
```

所以：

```cpp
dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i]);
```

前提是：

```cpp
j >= weight[i]
```

如果装不下：

```cpp
dp[i][j] = dp[i - 1][j];
```

**二维代码**

```cpp
int knapsack01(vector<int>& weight, vector<int>& value, int bagWeight) {
    int n = weight.size();
    vector<vector<int>> dp(n, vector<int>(bagWeight + 1, 0));

    for (int j = weight[0]; j <= bagWeight; ++j) {
        dp[0][j] = value[0];
    }

    for (int i = 1; i < n; ++i) {
        for (int j = 0; j <= bagWeight; ++j) {
            if (j < weight[i]) {
                dp[i][j] = dp[i - 1][j];
            } else {
                dp[i][j] = max(
                    dp[i - 1][j],
                    dp[i - 1][j - weight[i]] + value[i]
                );
            }
        }
    }

    return dp[n - 1][bagWeight];
}
```

**一维优化**

```cpp
dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i]);
```

只依赖上一行，所以可以压缩成一维：

```cpp
dp[j]
```

表示：

```text
容量为 j 的背包，当前处理过的物品里能获得的最大价值。
```

**一维代码**

```cpp
int knapsack01(vector<int>& weight, vector<int>& value, int bagWeight) {
    vector<int> dp(bagWeight + 1, 0);

    for (int i = 0; i < weight.size(); ++i) {
        for (int j = bagWeight; j >= weight[i]; --j) {
            dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
        }
    }

    return dp[bagWeight];
}
```

**为什么 01 背包容量倒序**

```text
倒序是为了防止当前物品在同一轮被重复使用。
```

如果正序：

```cpp
for (int j = weight[i]; j <= bagWeight; ++j)
```

那么 `dp[j - weight[i]]` 可能已经被当前物品更新过。

这样会变成同一个物品用了多次。

所以 01 背包必须：

```cpp
for (int j = bagWeight; j >= weight[i]; --j)
```

**背包问题模版**

```cpp
for (int i = 0; i < n; ++i) {
    for (int j = bagWeight; j >= weight[i]; --j) {
        dp[j] = std::max(dp[j], dp[j - weight[i]] + value[i]);
    }
}
```

### 5.2 完全背包

{% note purple 'fas fa-wand-magic-sparkles' %}
完全背包特点：每个物品可以选无限次。
{% endnote %}

{% note pink 'fas fa-bell' %}
  问题
{% endnote %}

每个物品可以选无限次，求最大价值。

{% note pink 'fas fa-bell' %}
 题解
{% endnote %}

**状态定义**

```cpp
dp[j]
```

表示：

```text
容量为 j 的背包能获得的最大价值。
```

**状态转移**

```cpp
dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
```

**代码**

```cpp
int completeKnapsack(vector<int>& weight, vector<int>& value, int bagWeight) {
    vector<int> dp(bagWeight + 1, 0);

    for (int i = 0; i < weight.size(); ++i) {
        for (int j = weight[i]; j <= bagWeight; ++j) {
            dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
        }
    }

    return dp[bagWeight];
}
```

**为什么完全背包容量正序**

```text
正序是为了允许当前物品在同一轮被重复使用。
```

对比：

```text
01 背包：每个物品只能用一次，所以容量倒序。
完全背包：每个物品可以无限用，所以容量正序。
```

#### 零钱兑换 II：组合数

**题目**

给不同面额硬币，每种硬币无限个，求凑成 `amount` 的组合数。

**状态定义**

```cpp
dp[j]
```

表示：

```text
凑成金额 j 的组合数。
```

**初始化**

```cpp
dp[0] = 1;
```

含义：凑成金额 0 有一种方法，什么都不选。

**转移**

```cpp
dp[j] += dp[j - coin];
```

**代码**

```cpp
int change(int amount, vector<int>& coins) {
    vector<int> dp(amount + 1, 0);
    dp[0] = 1;

    for (int coin : coins) {
        for (int j = coin; j <= amount; ++j) {
            dp[j] += dp[j - coin];
        }
    }

    return dp[amount];
}
```

**组合数 vs 排列数**

```text
先物品，再容量：组合数。
先容量，再物品：排列数。
```

组合不关心顺序：

```text
1 + 2 和 2 + 1 算一种。
```

排列关心顺序：

```text
1 + 2 和 2 + 1 算两种。
```

#### 零钱兑换 I：最少硬币数

**状态定义**

```cpp
dp[j]
```

表示：

```text
凑成金额 j 需要的最少硬币数。
```

**初始化**

```cpp
dp[0] = 0;
其他 dp[j] 初始化为 amount + 1
```

**状态转移**

```cpp
dp[j] = min(dp[j], dp[j - coin] + 1);
```

**代码**

```cpp
int coinChange(vector<int>& coins, int amount) {
    vector<int> dp(amount + 1, amount + 1);
    dp[0] = 0;

    for (int coin : coins) {
        for (int j = coin; j <= amount; ++j) {
            dp[j] = min(dp[j], dp[j - coin] + 1);
        }
    }

    return dp[amount] == amount + 1 ? -1 : dp[amount];
}
```

### 5.3 多重背包

{% note purple 'fas fa-wand-magic-sparkles' %}
多重背包特点：每个物品有固定数量。
{% endnote %}

{% note pink 'fas fa-bell' %}
  问题
{% endnote %}

每个物品有数量限制：

```text
weight[i]
value[i]
count[i]
```

{% note pink 'fas fa-bell' %}
 题解
{% endnote %}

**最容易理解的方法**

把每个物品拆成多个 01 物品。

例如：

```text
物品 A 数量 3
```

拆成：

```text
A1, A2, A3
```

然后按 01 背包做。

**暴力拆分代码**

```cpp
int multipleKnapsack(vector<int>& weight, vector<int>& value, vector<int>& count, int bagWeight) {
    vector<int> newWeight;
    vector<int> newValue;

    for (int i = 0; i < weight.size(); ++i) {
        for (int k = 0; k < count[i]; ++k) {
            newWeight.push_back(weight[i]);
            newValue.push_back(value[i]);
        }
    }

    vector<int> dp(bagWeight + 1, 0);

    for (int i = 0; i < newWeight.size(); ++i) {
        for (int j = bagWeight; j >= newWeight[i]; --j) {
            dp[j] = max(dp[j], dp[j - newWeight[i]] + newValue[i]);
        }
    }

    return dp[bagWeight];
}
```

**二进制拆分优化**

数量大时，不要一个个拆。

比如：

```text
count = 13
```

可以拆成：

```text
1, 2, 4, 6
```

这样仍然能组合出 0 到 13 的任意数量。

```cpp
int multipleKnapsackBinary(vector<int>& weight, vector<int>& value, vector<int>& count, int bagWeight) {
    vector<int> newWeight;
    vector<int> newValue;

    for (int i = 0; i < weight.size(); ++i) {
        int num = count[i];
        int k = 1;

        while (k <= num) {
            newWeight.push_back(weight[i] * k);
            newValue.push_back(value[i] * k);
            num -= k;
            k *= 2;
        }

        if (num > 0) {
            newWeight.push_back(weight[i] * num);
            newValue.push_back(value[i] * num);
        }
    }

    vector<int> dp(bagWeight + 1, 0);

    for (int i = 0; i < newWeight.size(); ++i) {
        for (int j = bagWeight; j >= newWeight[i]; --j) {
            dp[j] = max(dp[j], dp[j - newWeight[i]] + newValue[i]);
        }
    }

    return dp[bagWeight];
}
```

## 6.区间DP

{% note purple 'fas fa-wand-magic-sparkles' %}
区间 DP 的特点：
{% endnote %}

1. 状态表示一个区间 [l, r] 的答案。
2. 通常先枚举区间长度，再枚举左端点。

**通用模板**

```cpp
for (int len = 1; len <= n; ++len) {
    for (int l = 0; l + len - 1 < n; ++l) {
        int r = l + len - 1;
        // 根据 dp[l + 1][r], dp[l][r - 1], dp[l + 1][r - 1] 等更新
    }
}
```

**典型状态**

```cpp
dp[l][r]
```

表示：

```text
区间 [l, r] 内的最优答案。
```

**常见题型**

```text
最长回文子序列
戳气球
合并石子
括号匹配
```

### 6.1 戳气球模型

{% note pink 'fas fa-bell' %}
  关键思想
{% endnote %}

区间 DP 常常不是考虑“第一个操作谁”，而是考虑：

```text
最后一个操作谁。
```

戳气球中，枚举 `k` 作为区间 `(l, r)` 内最后一个被戳的气球。

{% note pink 'fas fa-bell' %}
 模板
{% endnote %}

```cpp
for (int len = 2; len < m; ++len) {
    for (int l = 0; l + len < m; ++l) {
        int r = l + len;

        for (int k = l + 1; k < r; ++k) {
            dp[l][r] = max(
                dp[l][r],
                dp[l][k] + dp[k][r] + cost(l, k, r)
            );
        }
    }
}
```

区间 DP：先长度，再左端点，最后枚举分割点。

## 7.树型DP

{% note purple 'fas fa-wand-magic-sparkles' %}

树形 DP 的特点：

{% endnote %}

- 状态定义在树节点上。
- 答案通常由左右子树返回。
- 常用 DFS 后序遍历。

---

### 7.1 打家劫舍 III

{% note pink 'fas fa-bell' %}
  问题
{% endnote %}

房子变成二叉树，不能同时偷父节点和子节点。

{% note pink 'fas fa-bell' %}
 题解
{% endnote %}

**状态定义**

每个节点返回两个值：

```cpp
{notRob, rob}
```

含义：

```text
notRob：不偷当前节点时，当前子树最大收益。
rob：偷当前节点时，当前子树最大收益。
```

**状态转移**

如果偷当前节点：

```cpp
rob = node->val + left.notRob + right.notRob;
```

如果不偷当前节点：

```cpp
notRob = max(left.notRob, left.rob) + max(right.notRob, right.rob);
```

**代码**

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};

vector<int> dfs(TreeNode* node) {
    if (!node) return {0, 0};

    vector<int> left = dfs(node->left);
    vector<int> right = dfs(node->right);

    int rob = node->val + left[0] + right[0];
    int notRob = max(left[0], left[1]) + max(right[0], right[1]);

    return {notRob, rob};
}

int rob(TreeNode* root) {
    vector<int> res = dfs(root);
    return max(res[0], res[1]);
}
```

---

### 7.2 二叉树最大路径和

{% note pink 'fas fa-bell' %}
  思路
{% endnote %}

每个节点要做两件事：

```text
1. 更新全局最大路径和。
2. 返回给父节点一条“单边最大贡献”。
```

为什么返回单边？

因为父节点连接当前节点时，只能继续走一条链，不能同时接左右两边。

**状态**

```cpp
dfs(node)
```

表示：

```text
从 node 往下走，能提供给父节点的最大单边路径和。
```

**转移**

```cpp
leftGain = max(0, dfs(node->left));
rightGain = max(0, dfs(node->right));

pathSum = node->val + leftGain + rightGain;
ans = max(ans, pathSum);

return node->val + max(leftGain, rightGain);
```



{% note pink 'fas fa-bell' %}
 代码
{% endnote %}

```cpp
class Solution {
public:
    int ans = INT_MIN;

    int dfs(TreeNode* node) {
        if (!node) return 0;

        int leftGain = max(0, dfs(node->left));
        int rightGain = max(0, dfs(node->right));

        int pathSum = node->val + leftGain + rightGain;
        ans = max(ans, pathSum);

        return node->val + max(leftGain, rightGain);
    }

    int maxPathSum(TreeNode* root) {
        dfs(root);
        return ans;
    }
};
```

## 8.状态压缩DP

状态压缩 DP 的特点：

```text
用二进制整数表示集合状态。
适合 n 比较小的问题，一般 n <= 20。
```

例如：

```text
state = 10110
```

表示某些元素已经被选过或访问过。

**常用位运算**

```cpp
state & (1 << i)        // 判断 i 是否在集合中
state | (1 << i)        // 把 i 加入集合
state ^ (1 << i)        // 切换 i 的状态
state & ~(1 << i)       // 把 i 从集合中删除
__builtin_popcount(s)   // 统计 s 中有几个 1
```

---

### 8.1 任务分配最小成本

{% note pink 'fas fa-bell' %}
  问题
{% endnote %}

有 `n` 个工人和 `n` 个任务，`n <= 15`。

```cpp
cost[i][j]
```

表示第 `i` 个工人做第 `j` 个任务的成本。

要求每个工人一个任务，每个任务一个工人，求最小总成本。

{% note pink 'fas fa-bell' %}
 题解
{% endnote %}

**状态定义**

```cpp
dp[state]
```

表示：

```text
已经分配任务集合为 state 时的最小成本。
```

`state` 里有几个 1，说明已经给几个工人分配了任务。

当前工人编号：

```cpp
worker = __builtin_popcount(state);
```

**状态转移**

枚举一个还没分配的任务 `task`：

```cpp
newState = state | (1 << task);
dp[newState] = min(dp[newState], dp[state] + cost[worker][task]);
```

**代码**

```cpp
int minCost(vector<vector<int>>& cost) {
    int n = cost.size();
    int full = 1 << n;
    const int INF = 1e9;

    vector<int> dp(full, INF);
    dp[0] = 0;

    for (int state = 0; state < full; ++state) {
        int worker = __builtin_popcount(state);
        if (worker >= n) continue;

        for (int task = 0; task < n; ++task) {
            if (state & (1 << task)) continue;

            int newState = state | (1 << task);
            dp[newState] = min(dp[newState], dp[state] + cost[worker][task]);
        }
    }

    return dp[full - 1];
}
```

---

**子集枚举**

状态压缩里经常要枚举 `state` 的所有子集。

模板：

```cpp
for (int sub = state; sub; sub = (sub - 1) & state) {
    // sub 是 state 的一个非空子集
}
```

如果要包含空集，可以最后单独处理 `0`。

**为什么这样能枚举子集**

```text
sub - 1 会改变最低位结构。
再 & state 可以保证结果仍然是 state 的子集。
```

常用于：

```text
分组任务
集合划分
最少批次数
旅行商问题变形
```

### 8.2 最少工作轮数模型

{% note pink 'fas fa-bell' %}
  问题
{% endnote %}

给一组任务，每个任务有耗时，每轮有时间上限 `limit`，每轮可以做若干任务，求最少几轮完成。

{% note pink 'fas fa-bell' %}
  题解
{% endnote %}

**思路**

1. 预处理每个集合 `state` 的任务总耗时。
2. 标记哪些集合能在一轮内完成。
3. 用 DP 枚举子集转移。

**状态定义**

```cpp
dp[state]
```

表示：

```text
完成 state 这个任务集合，最少需要几轮。
```

**转移**

枚举 `state` 的子集 `sub`：

```cpp
如果 sub 可以一轮完成：
dp[state] = min(dp[state], dp[state ^ sub] + 1);
```

**代码**

```cpp
int minWorks(vector<int>& tasks, int limit) {
    int n = tasks.size();
    int full = 1 << n;
    const int INF = 1e9;

    vector<int> sum(full, 0);
    vector<bool> ok(full, false);

    for (int state = 0; state < full; ++state) {
        for (int i = 0; i < n; ++i) {
            if (state & (1 << i)) {
                sum[state] += tasks[i];
            }
        }
        ok[state] = sum[state] <= limit;
    }

    vector<int> dp(full, INF);
    dp[0] = 0;

    for (int state = 1; state < full; ++state) {
        for (int sub = state; sub; sub = (sub - 1) & state) {
            if (ok[sub]) {
                dp[state] = min(dp[state], dp[state ^ sub] + 1);
            }
        }
    }

    return dp[full - 1];
}
```

## 9.数位DP

数位 DP 用来解决：

```text
统计 0 到 n 之间满足某些条件的数字个数。
```

常见限制：

```text
不含某个数字
数字和限制
相邻数字限制
出现次数限制
```

**核心参数**

通常 DFS 写法：

```cpp
dfs(pos, state, tight, started)
```

含义：

```text
pos：当前处理到第几位
state：之前数字形成的状态，比如数字和、上一位数字等
tight：当前是否受到 n 的上界限制
started：是否已经开始填非前导零数字
```

**记忆**

```text
数位 DP = 按位枚举数字 + 上界限制 tight + 状态缓存。
```

## 10.DP初始化技巧

不同问题初始化不同。

### 10.1 求最大值

通常初始化为：

```cpp
0
```

或者：

```cpp
-INF
```

如果状态可能不可达，要用 `-INF`。

### 10.2 求最小值

通常初始化为大数：

```cpp
const int INF = 1e9;
vector<int> dp(n, INF);
```

### 10.3求方案数

通常：

```cpp
dp[0] = 1;
```

含义：

```text
什么都不选，凑成 0，有一种方案。
```

### 10.4 DP 遍历顺序总结

遍历顺序由依赖关系决定。

```text
如果 dp[i] 依赖 dp[i - 1]，就从小到大。
如果 dp[l][r] 依赖更短区间，就先枚举区间长度。
如果 01 背包一维优化，容量倒序。
如果完全背包一维优化，容量正序。
如果树形 DP，通常后序 DFS。
如果状态压缩 DP，通常从小状态到大状态。
```
