# C++标准模版库STL

### 容器

- 顺序容器：`vector`、`deque`、`list`
- 关联容器：`set`、`map`、`multiset`、`multimap`
- 无序容器：`unordered_set`、`unordered_map`
- 容器适配器：`stack`、`queue`、`priority_queue`

### 算法

- `sort`
- `find`
- `binary_search`
- `lower_bound` / `upper_bound`
- `accumulate`
- `for_each`
- 其他常用算法

### 迭代器

- 输入 / 输出 / 前向 / 双向 / 随机访问迭代器
